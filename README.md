## 🧩 Project Workflow

1. **Choose the Website Theme**  
   Example: *AI Career Hub – A website that guides users in using AI for professional growth.*

2. **Generate the Design Using AI**
   - Used **Wix AI** and **Figma AI Plugin** to create homepage layout, color palette, and sections.
   - Prompt: *“Design a futuristic website homepage for an AI career guidance platform using minimal colors and curved UI blocks.”*

3. **Create Content with AI**
   - Used **ChatGPT + WordPress AI** to generate:
     - Homepage hero text  
     - Service descriptions  
     - Blog section content  
     - About Us and Contact page content  

4. **Add Automation & Interactivity**
   - Integrated **Zapier** to automate contact form submissions and connect to Google Sheets.  
   - Embedded **AI Chatbot Widget** (via Chatbase or Voiceflow) for personalized career advice.  

5. **Publish the Website**
   - Final site deployed on **Wix AI** under custom domain:  
     `https://your-ai-careerhub.wixsite.com` *(example placeholder)*
